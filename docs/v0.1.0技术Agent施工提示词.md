七、数据库与一致性
完整执行数据库参照文档。原 20 张表代表原业务职责，不强制照搬物理表数量，也不直接运行整套框架演示种子当作产品初始化。

经营数据按 workspace_id 归属；经验、复盘、能力提升和相应个人内容按 user_id 归属。服务端从认证上下文决定范围，不信任客户端归属字段。平台管理员字段不自动获取用户私有业务访问权。

金额按整数分保存，未知与零区分；统一有效收入、应收、多收和首页统计。保存取消删除历史，收入变动和恢复统一重算。
全局内部 ID 与业务编号分离，编号按经营簿或账号范围唯一；保留 KH／HZ／XM／BL／OD／SR／ZL／JYBX／CPBX、NT／JGJ／MC／KD／SLHT／TJP 和 WeekR／MonthR／QuarterR 原规则，生成后固定、删除不复用、并发不撞号。
更新、删除、恢复及完成动作由数据库原子校验版本；旧版本返回冲突，不静默覆盖。保存事务与幂等键，重复新增、收入、沟通、日志不重复执行。
请求去重限定身份、归属、操作及内容；缓存重放仍重新授权。重要变更可追溯人、来源、时间和对象。
全部可部署结构变更生成 Prisma migrations，检查和验证迁移；不能用 db push 代替交付迁移。更新代码保护已有数据。
未来权限矩阵和删除恢复规则按文档保留；本期按个人版原操作实现，不增加团队授权 UI 或协作流程。

九、个人备份与回滚
实现备份数据／恢复数据，下载本人经营数据、私有内容、必要关联和资料指针；排除账号密码、会话、Agent 密钥、平台秘密及外部文件。
