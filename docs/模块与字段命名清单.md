# 光域空间 · 模块与字段命名清单

整理日期：2026-10-14（Asia/Shanghai）  
版本：光域空间 v0.1.0。  
状态：第 2–5 节及 B01、B02、B07 已确认；业务编号沿用原格式，账号采用用户名；内部技术键由技术 Agent 设计。  
配套：[第一版功能需求整合](第一版功能需求整合.md)、[产品设计文档](产品设计文档.md)。

## 1. 使用方式

本文提取原 App v1.0–v1.4 的模块、字段、分类、操作及跨页面称谓。第 2–5 节的新名称已确认为开发显示基线；第 6 节记录品牌、编号和运行文案的最终处理方式。

字段、区块、按钮和选项名称采用清楚、简短的通用用语，每个建议名称不超过 5 个字符。品牌标语、完整提示句、动态模板及编号处理说明以准确表达为准，不受短名称字数限制。已有通用名称优先保留；农活相关字段采用“任务”，区域相关字段采用“项目类型”，耕种日志采用“项目日志”。本轮仅调整显示名称建议，技术定位键、字段用途、选项、权限及操作范围保持原有规则。

- 标记“游戏”的优先调整；“隐喻”可按上手清晰度调整；通用名称可以直接确认保留。
- 同一字段的表单名、列表名、详情名用“／”列在一起，改名时应统一处理。
- 技术定位键来自原界面、共享类型或接口，用于找准对象，不是已经确定的 PostgreSQL 字段或新版 API 契约。
- `M` 为模块，`F` 为字段，`H` 为首页，`A` 为操作，`E` 为选项，`B` 为编号或品牌相关用语；这些编号仅用于本次命名讨论。
- 改名不自动增加模块、改变字段含义、增加日志操作或扩展团队功能。
