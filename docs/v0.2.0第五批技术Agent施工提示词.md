四、R14 实现要求

1. 任务列表
- 工具栏提供搜索、新增任务、查看历史任务，以及区域、项目、状态筛选和查看已删除入口；筛选名称沿用当前正式版。

- 组内展示任务名称、优先级、状态、所属项目、计划日期、截止日期，按优先级再按计划日期排序。
- 按项目组分页，默认 50 组，可选 20、50、100 组；查询、计数和翻页口径一致，不能先截取固定数量任务再在前端分组导致遗漏。
- 任务行勾选可快速完成任务；完成后刷新任务列表、分组计数、历史记录和受影响的关联摘要。
- 保留现有未关联项目任务、学习排期关联任务的可见性及既有操作，避免分组后遗漏已有任务。

2. 历史任务
- 提供日期选择、查看全部历史及返回当前任务入口。
- 日期筛选按完成时间工作，沿用现有时区及日期边界；不使用计划日期或截止日期替代完成日期。
- 筛选变化时重置到有效页码，保持列表、总数和分页结果一致。

3. 新增与编辑任务
- 字段顺序为：必填任务名称、所属项目、关联客户、关联合作方、任务状态、优先级、计划日期、截止日期、说明、备注、资料链接；实际字段标签沿用当前正式版。
- 关联客户和关联合作方相互独立，可以同时选择并保存。
- 新增默认待办、P1（显示中）、计划日期当天；编辑正确回填已有值，不使用新建默认值覆盖空值或历史数据。
- 计划日期与截止日期并排，其余单列；资料链接逐条添加和删除，兼容已有数据。
- 取消、保存固定在抽屉底部，表单内容独立滚动，最后一个字段不被操作区遮挡；保存中防止重复提交，失败保留输入并显示错误。

4. 任务详情
- 任务名称作为标题，字段表不重复名称。
- 顶部提供编辑、删除、复制，底部提供标记完成；对已完成状态沿用现有完成/取消完成规则。
- 纵向字段表展示记录 ID、记录版本、任务状态、优先级、所属项目及项目类型、关联客户、关联合作方、计划日期、截止日期、完成时间、说明、备注、创建时间、更新时间；标签遵循现有正式名称。
- 复制可见业务编号；展示和维护现有资料链接。
- 完成操作成功后状态、完成时间和列表同步；失败时提示原因，不能留下与服务端不一致的完成状态。
